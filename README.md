# SpaceWorks-HQ/.github

Organisation-wide files for [Space Works](https://github.com/SpaceWorks-HQ), the open-source ecosystem for
makerspaces, fab labs, hackerspaces, tool libraries and maker communities.

## What's here

| Path | Purpose |
|---|---|
| [`profile/README.md`](profile/README.md) | The public profile shown at [github.com/SpaceWorks-HQ](https://github.com/SpaceWorks-HQ) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | How to contribute to any Space Works repository |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Contributor Covenant 2.1 |
| [`SECURITY.md`](SECURITY.md) | How to report a vulnerability privately |
| [`SUPPORT.md`](SUPPORT.md) | Where to get help |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE) | Bug report, feature request and "tell us about your space" forms |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | The pull request checklist |

GitHub uses these as **defaults** for every public SpaceWorks-HQ repository that doesn't have its own file of
the same type. A repository's own file always wins, so a repository can override any of them.

## Changing these files

Branch off `dev`, open a pull request against `dev`, and a maintainer promotes it to `main`. Changes to
`main` go live across the organisation immediately.
